**Gold Price Prediction**

**Project Overview**

This project focuses on predicting the future price of gold using historical gold price data. By analyzing trends, seasonality, and patterns in gold prices, the model aims to provide accurate forecasts to assist investors and traders in making informed decisions.

**Dataset**

The dataset used in this project is sourced from Kaggle:

Source: Gold Price Data on Kaggle

Description: The dataset contains historical gold price data including Date,SPX,GLD,USO,SLV,EUR/USD.

link : https://www.kaggle.com/datasets/altruistdelhite04/gold-price-data
